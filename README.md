# 💼 Employee Salary Prediction

Predict employee salaries instantly using a Machine Learning model built with **Python**, **Scikit-learn**, and **Streamlit**.

🌐 **Live Demo:** https://employeesalalryprediction-dylh95sxyo7bfzwfnsxadi.streamlit.app/

---

## 📌 Project Overview

The **Employee Salary Prediction** application estimates an employee's salary based on multiple factors such as:

- 👨‍💼 Experience
- 🎓 Education Level
- 💻 Job Role
- 📍 Location
- 📊 Other relevant inputs

Simply enter the required details, click **Predict**, and the application generates an estimated salary using a trained Machine Learning model.

## 🚀 Installation

### 1️⃣ Clone the repository

```bash
git clone https://github.com/yourusername/Employee_Salary_Prediction.git
```

### 2️⃣ Navigate to the project

```bash
cd Employee_Salary_Prediction
```

### 3️⃣ Install dependencies

```bash
pip install -r requirements.txt
```

### 4️⃣ Run the application

```bash
streamlit run app.py
```
